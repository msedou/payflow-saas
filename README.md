# 🚀 PayFlow SaaS

Scalable Payroll Microservices Platform inspired by Stripe & PayFit.

## 🏗️ Architecture

- Microservices architecture
- Event-driven (future Kafka integration)
- Clean Architecture + DDD
- .NET / Rust / Node.js
- PostgreSQL

## 📦 Services

- API Gateway
- Auth Service
- Employee Service
- Payroll Service
- Tax Engine (Rust)
- Payment Service
- Billing Service
- Notification Service
- Reporting Service
